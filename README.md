# Grandma's Word on AI

An entry for make.fun's **One Word From Grandma** bounty: exactly one word,
the word my grandma would text about AI — a scrap of text-speak, the sound
she makes when she imitates a robot.

`main.py` writes that single word to `entry.txt`, deterministically, with no
network and no model calls.
